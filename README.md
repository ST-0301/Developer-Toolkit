# Developer Toolkit

A Python-based productivity toolkit featuring a collection of utilities to streamline engineering workflows. This application is built with Streamlit and can be run as a standard web application or a standalone desktop application via PyWebView.


## 🛠️ Features

* **📝 Daily Journal:** 🚧 *(Under Construction)* Automate engineering work logs using local AI models.
* **💬 Communication Translator:** 🚧 *(Under Construction)* Transform raw thoughts into professional workplace communication.
* **📄 Code Formatter:** Batch format local code files for AI web chat prompts.
* **🔍 Code Difference Checker:** Compare code side-by-side with formatting noise reduction and statistics.


## 🚀 Installation & Setup

Initialize your environment and install the required dependencies:
```bash
pip install -r requirements.txt
```

## 💻 Usage

**Run as a Web Application:**<br>
To run the standard Streamlit interface in your browser:
```bash
streamlit run app.py
```
<br>

**Run as a Desktop Application:**<br>
Execute the desktop wrapper to launch the toolkit headlessly via Streamlit and display it in a dedicated local window:
```bash
python desktop_app.py
```
